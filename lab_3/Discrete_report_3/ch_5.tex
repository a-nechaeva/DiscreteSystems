\chapter{Исследование влияния неточности компенсации полюсов}
\label{ch:chap5}
Исследуем влияние неточности компенсации полюсов объекта на качество процесса управления, увеличив и уменьшив значение постоянной времени $T_2$ объекта управления на $20 \%$. Для этих двух случаев рассчитаем значения параметров дискретного регулятора
\begin{equation}
	\begin{cases}
		T_2^* = T_2 + 20 \% = 1.08
		z_1 = d_1 = e^{-\frac{T}{T_1}} =0.6065\\
		z_2 = d_2 = e^{-\frac{T}{T_2}} = 0.7575
	\end{cases}
\end{equation}
\begin{equation}
	num(z) = z^2 + (-d_1-d_2)z + d_1d_2 = z^2 - 1.3640z+0.4594
\end{equation}
\begin{equation}
	\begin{cases}
		T_2^* = T_2 - 20 \% = 0.72
		z_1 = d_1 = e^{-\frac{T}{T_1}} =0.6065\\
		z_2 = d_2 = e^{-\frac{T}{T_2}} = 0.6592
	\end{cases}
\end{equation}
Найдем коэффициенты числителя регулятора:
\begin{equation}
	num(z) = z^2 + (-d_1-d_2)z + d_1d_2 = z^2 -1.2658 z+0.3998
\end{equation}
Значение $q_0= 10$ -- то же значение, что было выбрано ранее.
