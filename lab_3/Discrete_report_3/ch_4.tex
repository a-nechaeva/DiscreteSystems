\chapter{Исследование влияния параметра $T$}
\label{ch:chap4}
Исследуем влияние периода дискретизации $T$ на качество процесса управления. Для этого установим значение периода дискретизации $T = \frac{T_1}{4} = 0.15$. Рассчитаем новые значения параметров дискретного регулятора
\begin{equation}
	\begin{cases}
		z_1 = d_1 = e^{-\frac{T}{T_1}} =0.7788\\
		z_2 = d_2 = e^{-\frac{T}{T_2}} = 0.8465
	\end{cases}
\end{equation}
Найдем коэффициенты числителя регулятора:
\begin{equation}
	num(z) = z^2 + (-d_1-d_2)z + d_1d_2 = z^2 - 1.6253z+0.6592
\end{equation}
Значение $q_0= 10$ -- то же значение, что было выбрано ранее.
