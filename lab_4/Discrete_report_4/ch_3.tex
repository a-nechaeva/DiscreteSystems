\chapter{Дискретизованный ОУ с ЭНП}
\label{ch:chap3}
Дискретизованный ОУ с ЭНП задан передаточной функцией
\begin{equation}
	HG(z) = \frac{0.03(z+0.75)}{z^2 - 1.5 z + 0.5}
\end{equation}
Разработаем дискретный регулятор, обеспечивающий заданное расположение полюсов замкнутой системы так, чтобы отклик замкнутой системы был бы колебательным с заданными $\zeta$ и $\omega_d$. Установившаяся ошибка для линейно нарастающего входа должна быть равна $K_v$. Период дискретизации $T$.

Реакция системы управления определяется расположением полюсов замкнутой системы.

Пусть передаточная функция ОУ вместе с ЭНП имеет вид
\begin{equation}
	HG(z) = \frac{0.03(z+0.75)}{z^2 - 1.5 z + 0.5}
\end{equation}
Задача состоит в том, чтобы разработать дискретный регулятор такой, чтобы замкнутая система имела колебательный отклик с декрементом затухания $\zeta = 0.7$ и частотой колебаний $\omega_d = 5$ рад/с. Установившаяся ошибка для ступенчатого входа должна быть равна нулю, а установившаяся ошибка для линейно нарастающего входа должна быть $0.2$ при периоде дискретизации $T = 0.2$.
\begin{equation}
	z_{1,2} = e^{-\zeta \omega_n T \pm j \omega_n T \sqrt{1 - \zeta^2}} = e^{-\zeta \omega_n T} \left(\cos \omega_n T \sqrt{1 - \zeta^2} \pm i\sin \omega_n T \sqrt{1 - \zeta^2} \right)
\end{equation}
Формула связи $\omega_n$ и $\omega_d$
\begin{equation}
	\omega_d = \omega_n \sqrt{1 - \zeta^2} \Rightarrow
	\omega_n = \frac{\omega_d}{\sqrt{1 - \zeta^2}} = \frac{5}{\sqrt{1 - 0.7^2}} \approx 7.0014
\end{equation}
Требуемые полюса
\begin{equation}
	z_{1,2} = e^{-0.7 \cdot 7.0014 \cdot 0.2} \left(\cos (5 \cdot 0.2) \pm i \sin (5 \cdot 0.2) \right) = 0.2027 \pm 0.3158 i
\end{equation}
Желаемая передаточная функция замкнутой системы будет иметь вид
\begin{multline}
	T(z) = \frac{b_0z^2 + b_1 z + b_2  + \cdots}{\left(z -0.2027 - 0.3158 i \right)\left(z -0.2027 + 0.3158 i \right)} = \\
	= \frac{b_0z^2 + b_1 z + b_2  + \cdots}{z^2 - 0.4055 z + 0.1408} \frac{b_0 + b_1 z^{-1} + b_2 z^{-2} + \cdots}{1 - 0.4055 z^{-1} + 0.1408 z^{-2}}
\end{multline}
Из соображений физической реализуемости, $b_0 = 0$ и лишь коэффициенты $b_1$ и $b_2$ будут ненулевыми
\begin{equation}
	T(z) = \frac{b_1z^{-1} + b_2 z^{-2}}{1 - 0.4055 z^{-1} + 0.1408 z^{-2}}
\end{equation}
Для определения коэффициентов числителя передаточной функции воспользуемся заданными точностными характеристиками. Установившаяся ошибка имеет вид
\begin{equation}
	E(z) = R(z) \left(1 - T(z)\right)
\end{equation}
Для единичного ступенчатого входного сигнала установившуюся ошибку можно определить с помощью теоремы о конечном значении
\begin{equation}
	E_{ss} = \lim\limits_{z \to 1} \frac{z - 1}{z} \frac{z}{z - 1} [v] = 1 - T(1)
\end{equation}
Установившаяся ошибка примет нулевое значение при $T(1) = 1$. 
\begin{equation}
	T(1) = \frac{b_1 + b_2}{0.7353} = 1, \Rightarrow b_1 + b_2 = 0.7353
\end{equation}
\begin{equation}
T(z) =	\frac{b_1 z + b_2}{z^2 -0.4055 z + 0.1408}
\end{equation}
Пусть $K_v = 0.25$ -- добротность по скорости замкнутой системы, тогда установившаяся ошибка при линейно нарастающем входном воздействии будет иметь вид
\begin{equation}
	E_{ss} = \lim \limits_{z \to 1} \frac{z-1}{z} \frac{Tz}{\left(z-1\right)^2} \left[1 - T(z)\right] = \frac{1}{K_v}
\end{equation}
или, используя правило Лопиталя
\begin{equation}
	\left. \frac{dT}{dt}\right|_{z=1} = - \frac{1}{K_v T}
\end{equation}
Тогда подставив значения, получим
\begin{multline}
		\left. \frac{dT}{dt}\right|_{z=1} = \frac{b_1 \left(z^2 - 0.4055 z + 0.1408\right) - \left(b_1 z + b_2\right) \left(2z - 0.4055\right)}{\left(z^2 - 0.4055 z + 0.1408\right)^2} = \\ =
		- \frac{1}{K_v T} = -\frac{1}{0.05} = -20
\end{multline}
что дает
\begin{equation}
	\frac{0.7357 b_1 - 1.5945\left(b_1 + b_2\right)}{0.7357^2} = -20 \Rightarrow 0.8592 b_1 + 1.5945 b_2 = 10.8139
\end{equation}
Решим систему
\begin{equation}
	\begin{cases}
		b_1 + b_2 = 0.7353\\
		0.8592 b_1 + 1.5945 b_2 = 10.8139
	\end{cases} \Rightarrow \begin{cases}
	b_1 = -13.1119\\
	b_2 = 13.8472
	\end{cases}
\end{equation}
Получим желаемую передаточную функцию замкнутой системы в виде
\begin{equation}
	T(z) = \frac{-13.1119z + 13.8472}{z^2 -0.4055 z + 0.1408}
\end{equation}
Тогда передаточная функция регулятора будет иметь вид
\begin{multline}
	D(z) = \frac{1}{HG(z)} \frac{T(z)}{1-T(z)} = \frac{z^2 - 1.5 z + 0.5}{0.03(z+0.75)} \cdot \frac{T(z)}{1-T(z)} = \\ =
	\frac{z^2 - 1.5 z + 0.5}{0.03(z+0.75)} \cdot \frac{-13.1119z + 13.8472}{13.1119z - 13.8472 + z^2 -0.4055 z + 0.1408} = \\=
		\frac{z^2 - 1.5 z + 0.5}{0.03(z+0.75)} \cdot \frac{-13.1119z + 13.8472}{z^2 + 12.7064z - 13.7064} =\\=
		\frac{-13.1119 z^3 + 33.5150 z^2 -27.3267 z + 6.9236}{0.03z^3 + 0.4037z^2 -0.1253z -0.3084}
\end{multline}
