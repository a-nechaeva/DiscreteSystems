\chapter{Исследование влияния дискретного элемента на непрерывную систему}
\label{ch:chap1}

Запишем значения коэффициента передачи ОУ и периода дискретизации согласно варианту: $T = 0.2$ с, $K_{CO} = 4$.

В среде Matlab Simulink реализуем схему (рисунок \ref{1_sch}).

\begin{figure}[h]
\center{\includegraphics[width=1\linewidth]{pic/1_sch.png}}
\caption{Схема моделирования.}
\label{1_sch}
\end{figure}

Выведем передаточную функцию для схемы на рисунке \ref{1_sch}.

Запишем формулу для разомкнутой системы

\begin{equation}
	W_{open}(z) = K_{BF} · K_{CO} · W_d(z), 
\end{equation}

где $W_d(z)$ -- передаточная характеристика экстраполятора нулевого порядка (ZOH).

\begin{equation}
	W_d(z) = Z\{ZOH · 1/s\} = Z\{(1 - e^{-Ts})/s²\} = \frac{T}{z - 1}
\end{equation}

Формула ПФ для замкнутой отрицательной обратной связью системы вычисляется по формуле

\begin{equation}
	W(z) = \frac{	W_{open}(z)}{	W_{open}(z) + 1}
\end{equation}

В итоге для замкнутой системы получаем
\begin{equation}
	W(z) = \dfrac{K_{FB} K_{CO}  T}{z + K_{FB} K_{CO} T - 1}
\end{equation}

Путем настройки коэффициента $K_{FB}$ найдем такое его значение, которое соответствует границам устойчивости (нейтральной и колебательной) замкнутой системы. При $K_{FB} = 0$ достигается граница нейтральной устойчивости, при $K_{FB} = 2.5$ достигается граница колебательной устойчивости, графики соответствующих переходных процессов представлены на рисунках \ref{1_trans_1} и \ref{1_trans_2}.

Рассмотрим влияние экстраполятора нулевого порядка на свойства устойчивости замкнутой системы. Пусть $K_{FB} = 2.5$, то есть система находится на колебательной границе устойчивости, при увеличении периода дискредитации система становится неустойчивой (рисунок \ref{1_trans_zoc_1}). В случае уменьшения периода дискретизации колебания становятся затухающими (рисунок \ref{1_trans_zoc_2}).
